First release.

**Windows:** download `letta-tether.exe` and double-click it. Windows will warn that it's from an unknown publisher (it isn't code-signed): **More info → Run anyway**. A setup page opens in your browser.

**Mac (untested):** download `letta-tether-mac.zip`, unzip, right-click the app → **Open** → **Open**. Please tell us if it works.

**Linux:** `curl -fsSL https://raw.githubusercontent.com/tanner-caffrey/letta-tether/main/install-linux.sh | sh`

See the [README](https://github.com/tanner-caffrey/letta-tether#readme) for what it does and how to remove it. `SHA256SUMS.txt` has checksums for every file.
