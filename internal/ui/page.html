Letta Tether

Run your Letta agents on your own computer.

What this does

Your Letta agent has two parts:

  • Its memory and conversations. These live in your Letta account, like always. Nothing here changes them or moves them.
  • A computer to think and work on. When your agent runs a command, reads a file or uses a tool, it happens on some computer. This app lets it be this one, instead of one you rent from Letta.

Two things to know:

  • Your agent can use this computer while it's connected. Only connect agents you trust.
  • When this computer is off or asleep, your agent can't use it. Messages wait and get answered when it's back.

Letta Tether isn't made by Letta. It's free, and everything it does is public on GitHub.

Setting up a new channel

Each one is set up once, with Letta's own setup in a terminal (it asks for things like a bot token):

letta channels configure telegram (or discord, slack, whatsapp, signal)

Then come back here and press Refresh. Messages from someone new get a pairing code back; paste it under that channel to connect them to an agent.
